# Chrome Web Store privacy practices

## Permissions

- `storage`: local settings, statistics, blocked-handle display data, diagnostic logs, remote recognition-data cache, and muted-word sync progress.
- `alarms`: refreshes inert recognition data once per hour.
- `https://raw.githubusercontent.com/BaikkAce/x-yellow-blocker/*`: reads only `keywords.txt` and `lure-samples.json`.
- `https://pbs.twimg.com/*`: displays public avatars captured locally when X confirms a block.

## Data handling

- Detection is local.
- No account blocklist is downloaded.
- No handles, posts, replies, avatars, installation identifiers, browsing history, cookies, or logs are uploaded.
- Remote files contain only bounded text data and cannot provide executable code, selectors, regexes, thresholds, or algorithms.
