# Chrome Web Store listing

## English

### Short description

Detects adult-solicitation spam in replies under opened X posts and blocks high-confidence authors through X's visible interface.

### Details

- Processes only replies under an opened post.
- Never moderates root posts, home/recommended timelines, search results, or profile pages.
- Uses local rules and X's visible Block menu.
- Scans existing muted words first and adds only missing words.
- Refreshes curated keywords and lure-language examples from a fixed GitHub repository.
- Does not download account blocklists or upload user data.
- Does not execute remotely hosted code.

识别 X 帖子详情页评论区中的成人引流垃圾回复，并通过 X 原生界面屏蔽高置信度作者。

### 详细说明

- 从固定 GitHub 仓库更新人工维护的屏蔽词和引流语言样本。
- 不下载账号名单，不上传任何用户数据。
- 不执行远程托管代码。
